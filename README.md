# 🎮 しりとりゲームサイト

このサイトは、日本語のしりとりを楽しく遊べるWebサイトです。  
画像を見て単語を考え、最後の文字から次の言葉をつなげていきます！

## スタート単語

しりとりの流れ：

シマイナガ → ガンダム → ムメンライダー → ダルマ → マリオカド → ドライブ → ブルマ → マリク → クナイ → イザナミ

---

## 単語紹介

### しマイナガ
かわいいシマエナガ風キャラクター。ゲームのスタート画像！

### ガンダム
有名な巨大ロボットアニメシリーズ。

### ムメンライダー
『ワンパンマン』に登場するヒーロー。自転車で戦う勇敢なキャラ。

### ダルマ
日本の縁起物。願い事をするときにも使われる。

### マリオカード
マリオがデザインされたカード。ゲームやコレクションとして楽しめるアイテム。

### ドライブ
車やバイクで走ること。お出かけ気分！

### ブルマ
昔の体育着として知られる服。

### マリク
『遊☆戯☆王』に登場するキャラクター。ミステリアスで強い印象を持つ人気キャラ。

### クナイ
忍者が使うことで有名な道具。

### イザナミ
日本神話に登場する神様。
